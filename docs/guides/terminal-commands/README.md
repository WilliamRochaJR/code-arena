# Comandos de terminal

Este diretorio e um catalogo de estudo dos comandos usados no Code Arena. Ele
nao e um diario: cada comando reutilizavel aparece uma unica vez, no arquivo do
assunto correspondente.

## Como manter

- Consulte o assunto antes de adicionar um comando.
- Nao registre datas, repeticoes ou a sequencia completa de uma tarefa.
- Nao registre leituras ocasionais sem valor como procedimento reutilizavel.
- Explique objetivo, efeito e cuidados relevantes.
- Use placeholders como `<branch>` e `<arquivo>` para valores variaveis.
- Nunca inclua tokens, senhas, chaves ou valores reais de `.env`.
- Crie um link em vez de copiar um comando catalogado em outro assunto.
